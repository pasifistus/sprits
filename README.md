# sprits

Simple static website to track how many drinks each person has had tonight.

## Run locally

Open `/home/runner/work/sprits/sprits/index.html` in a browser.

## Deploy publicly (GitHub Pages)

1. Push this repository to GitHub.
2. In repository **Settings → Pages**, set:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or your default branch), folder `/ (root)`
3. Save and wait for deployment.
4. Your public static URL will appear in the Pages settings.
