# Sprits Tonight

Simple static website to track how many drinks each person has had tonight.

## Features

- Add names to a list.
- Increase the drink counter for each name (`+1 drink` button).
- Data is saved in browser `localStorage`.
- Counters reset automatically on a new day.

## Run locally

Open `/home/runner/work/sprits/sprits/index.html` in your browser.

## Host publicly with GitHub Pages

1. Push this repository to GitHub.
2. In GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main` (or your default branch), folder `/ (root)`
4. Save. GitHub will publish the site at:
   - `https://<your-username>.github.io/sprits/`
